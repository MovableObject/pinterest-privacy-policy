# Privacy Policy

**Last updated:** March 28, 2026

## Overview

This application ("the App") uses the Pinterest API for personal, non-commercial purposes. This privacy policy describes how data is collected, used, and handled.

## Data Collection

The App accesses Pinterest data solely through the official Pinterest API. The only data accessed is:

- Publicly available Pinterest content (pins, boards)
- Basic account information as authorized by the user during OAuth authentication

## Data Usage

All data accessed through the Pinterest API is used exclusively for personal purposes. No data is:

- Sold to third parties
- Shared with third parties
- Used for advertising or marketing
- Stored beyond what is necessary for the App to function

## Data Storage

Data retrieved from the Pinterest API is processed locally and is not stored on any external servers.

## Third-Party Services

This App interacts only with the Pinterest API. No other third-party services receive your data.

## Contact

If you have questions about this privacy policy, please open an issue on this GitHub repository.

## Changes

This privacy policy may be updated from time to time. Changes will be reflected by the "Last updated" date above.
